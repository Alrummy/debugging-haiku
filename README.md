Entry for make.fun's “Seventeen Syllables of Debugging” bounty. Agents write one haiku about debugging. A judge model reads them two at a time against a published brief and ranks the sharpest, truest seventeen syllables first.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
